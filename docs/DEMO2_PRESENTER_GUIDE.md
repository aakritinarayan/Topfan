# Demo 2 presenter guide: "Tell it what you want; it prepares, you decide"

**Before you start**
- Open `http://localhost:5173/demo/ai-content?resetMock=1` on a laptop (1512×805 or larger works best; 1126×797 is fine).
- On a phone, the whole desktop layout is fitted to the screen. Use a laptop for presenting.
- Open the assistant with the mascot.
- If Content Autopilot's notice appears, close it.

Every phrase below is typed into the assistant exactly as written. All of them work without a live model.

## 1. Welcome (30 s)
The panel says **"What would you like to create?"** and offers three ideas: Create a post, Plan my content, Create a newsletter. **More ideas** reveals Plan a fan experience and Plan my entire week.

> Say: "No dashboard to learn. You say what you want."

## 2. A post with an image (2 min)
1. Type **"Create a training update post for this week"**. An Images post draft appears, built from AJ's own training notes, marked **Draft**, with its sources listed.
2. Click **Add an image** → **Generate an original image**. Point out the brief, the two directions, and the **Simulated** label.
3. Pick one, then type **"Make it darker"** and pick the revision.
4. Click **Open in New Post**. The real composer opens already filled in. Add a few words, and the card now says "Edited by you".

> Say: "Publishing is still the creator's own click."

## 3. Members-only content (2 min)
1. Type **"Create an exclusive post for my Gold members"**. The assistant finds the Gold Plan and explains plainly that a post's Lock is pay-to-unlock and can't target one plan. It offers what does work.
2. Type **"Make it only for Platinum members"**. It answers: "I couldn't find a Platinum membership in your current plans."
3. Click **Use Gold Plan** → **Lock it with an unlock price**, then type **"12"**.
4. Type **"Prepare a public teaser"**. You get a separate public post that doesn't leak the locked content.
5. Optional: type **"Let fans unlock this using loyalty points"**, then **"250"**. Click **Open in New Post** and open **Lock**: Loyalty Points is ticked with 250 Points. (NFT works the same way, but the creator pastes the contract address; the assistant never invents one.)

> Say: "It never fakes a feature the platform doesn't have."

## 4. Newsletter with a blocker (1.5 min)
1. Type **"Turn this post into a newsletter"**. It answers: "Your newsletter draft is ready, but email sending needs verification…", with Save the draft and Review email setup.
2. Type **"Send it only to Gold subscribers"**. This works, because newsletters support plans.
3. Click **Open and save the draft**, then use the page's **Save Draft**. The item is now "Saved in TopFan", not "Sent".

## 5. A fan experience (1.5 min)
1. Type **"I want to sell tickets for a fan session"**. It asks whether the creator means a booking or tickets for a set date. Pick **Book a time with me**.
2. When it asks for a price, type **"75"**. (Typing "free" is declined with an explanation.)
3. Click **Open in Add Experience**. The Create Experiences form is prefilled and **Disabled** until the creator enables it. (Google/Outlook Calendar buttons say plainly that nothing is connected in this demo.)
4. Back in the assistant, type **"Announce it"**. The announcement post is prepared and the booking link is flagged until the experience is live.

## 5b. Ideas → full drafts (2–3 min)
Use these when you want to show the assistant doing the creative preparation.

1. **Experience ideas.**
   - Type **"Help me plan an experience"**. Four idea cards appear, each with an image and a supported Experience type.
   - Type **"Use the first option"**. The full proposal appears with a preview image, and it asks for your price.
   - Optional: **"Make it more premium"**, **"Change it to a one-to-one call"**, **"Generate another image"**.
   - Type **"60"**, then click **Open in Add Experience**. Title, description, type, duration, price and image are filled in, and it's set to **Disabled**.
2. **Newsletter topics.**
   - Back in the assistant, type **"Help me create a newsletter"** and click **Use this topic** on one card.
   - The full draft (subject, intro, sections, CTA, cover) is ready. It notes that email sending needs verification.
   - Optional: **"Add a stronger CTA"**.
   - Click **Open in New Newsletter**. The headed sections and cover are in the editor. Click **Save as Draft**.
3. **A post with copy and images together.** Type **"Create a motivational post about my snowboarding journey"**. You get a caption from AJ's notes with hashtags, plus two image options. Pick one, then **Open in New Post**.
4. **Connected tasks.** With the experience as the last one you worked on, type **"Create a post and newsletter to promote this"**. Both are linked to that same experience, and nothing is posted or sent.

Other follow-ups that work:
- **"Give me more ideas"** gives different concepts.
- **"Use the second option"**
- **"Make the caption shorter"**
- **"Continue editing my previous draft"**

Picking another idea keeps the earlier draft. Text you've edited on the page is never rewritten.

## 6. The whole week (2 min), the flagship
1. Type **"I'm busy this week. Plan a training post, an exclusive post for members, a newsletter and a paid fan session."** The panel shows **"Your week is prepared."** with counts and four rows: Mon post, Wed members-only post, Fri newsletter, Sat experience.
2. Type **"Move the newsletter to Thursday"**. Only that row moves.
3. Type **"Remove the experience"**. The newsletter that mentioned it is flagged for review.
4. Type **"Approve the ready drafts"**. The approved drafts are marked "Approved". Nothing is posted.

Variant (Link in Bio in the week): type **"Plan my week and help promote my upcoming experience"**. You get five connected tasks: experience announcement, members-only post, newsletter, experience and a Link in Bio update waiting for the booking link. Then type **"Rename the experience to Sunrise Park Session"**: the announcement, newsletter and Link in Bio update are marked for review, not silently rewritten.

> Say: "Approval isn't publishing."

## 6b. Link in Bio (2–3 min)
Use the avatar or the **Edit Preferences** button under AJ's name, then **Link In Bio**. The panel says: "Your Link in Bio brings your content, offerings, and social profiles together in one place. I can help you organize it."

1. Click **Set up my links**. It explains what it will check; click **Prepare my links**. Each row shows a priority, whether it's Live or External, and its full address on click. Untick one, rename one, then click **Add selected links**.
2. The original editor opens with the changes in its preview (the training session as a Store item card). Click **Save Changes** → **Save Changes**. The panel confirms only what actually saved.
3. Type **"Put my training session at the top"**. After step 1 it's already first, so it says so instead of adding it twice.
4. Type **"Make my links better"**: Click Here → a clearer title, the duplicate IG link, and the outdated Summer Park Camp link replaced.
5. Optional: **"Add my social profiles"**, **"Suggest a short bio for my Link in Bio"**, or **"Check my Link in Bio"**.

## 7. Keep it going (30 s)
Type **"I don't want to plan this every week"**. Content Autopilot's preferences open, with a note that it prepares a weekly batch and nothing posts on its own.

## Recovering
- Lost your place? Type **"Continue my week"** or **"Continue my newsletter"**, or use the **Continue my …** chip on the Feed.
- Start over: reload with `?resetMock=1`. This resets the mock data only.

## What's simulated (say it if asked)
Image generation, timing suggestions, and the email-verification state are all mock-only. No real network calls, emails, payments or uploads happen.
