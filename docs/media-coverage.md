## Intentional empty states and fixtures

- Text and poll posts have no image, which is their design in TopFan.
- Discount Codes stay text-based.
- Empty lists (for example a search with no results) show TopFan's own empty-state copy.
- Content Autopilot, missing photo: `?apFixture=missing-asset` removes the requested photo, so the draft shows “No photo yet” and is held. It is never replaced automatically. Run `tests/e2e/autopilot.mjs` (scenario C).
- Content Autopilot, unapproved photo: `?apFixture=unapproved-asset` keeps the photo, but it isn't approved for posting yet. Run `tests/e2e/autopilot.mjs` (scenario C2).
- Load failures: `tests/e2e/media-fallback.mjs` blocks files on purpose and checks three things:
  - The content-type fallback (`public/assets/illustrations/fallback-*.svg`) replaces the file in a slot of the same size.
  - No broken-image icon appears.
  - The failure is logged to `window.__mediaErrors` and the console.

## Known limitations

- Photos come from Wikimedia Commons under CC0, public domain, CC BY or CC BY-SA. Attribution is in the inventory above. Before any public or commercial use, a person should review the licenses (CC BY-SA adaptations, crops in this case, carry share-alike terms).
- AJ White's profile picture is a portrait supplied by the designer (`scripts/media/supplied/`, placed by `scripts/media/supplied.mjs`), and its use was confirmed by them. The original shirt shows a real sportswear logo, so the avatar crop stops above it. Fetched Commons photos never use an identifiable person for a creator or fan. Other creators use action, landscape or object photography, and fans have original illustrated avatars.
- Brands are fictional: Ridgeline, Northpeak, Summit Soda, Glacier Hydration and Corner Mart, with original SVG art. A few photos still show small incidental marks:
  - An avalanche airbag pack shows the manufacturer's label (`posts/airbag-pack`).
  - A helmet sticker reads a resort name (`posts/goggles`).
- The video clips are short, muted demo loops (about 8 s). They aren't the creator's real footage.
- Livestream content is labeled “Recorded preview”. The demo has no live video.
- The default seed has no events, which is the spec default. For the event-detail route the audit adds the same sample event that the in-app Bandsintown import creates. Images on event cards appear once an event exists.
- E-book covers (3:4) are center-cropped in the square store cards. The full cover shows on the product page.
- Posts and chat media created during the demo through New Post or the message composer show the existing placeholder, because the mock upload stores only the file name. Nothing real is uploaded.
- The Newsletter band on Home keeps its CSS gradient (the reference shows a stage photo there, and the demo has no suitable licensed photo).
- The Monetize Single Video uses the vertical park reel, because that player is portrait. The episode and single clips are 5–8 s, and their listed durations match the files.
- The audit covers each route's default state. Nested states are checked separately and aren't in the table above:
  - `tests/e2e/media-nested.mjs`: Messages thread, tabs and modals; Insights lists; Wallet categories; refund detail; Fulfillment; Activity; Delegation.
  - `tests/e2e/autopilot.mjs`: Autopilot draft media states.
  - `tests/e2e/media-fallback.mjs`: failures and playback.
